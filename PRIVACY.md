# ExceptionOS Privacy

ExceptionOS stores goals, plans, progress notes, evidence links, and outcomes in the signed-in user's private Anna storage. It does not run a separate account system or backend database.

Goal details are sent to Anna's configured model provider only when the user checks the consent control and selects **Build my action plan**. Model credentials are managed by Anna and are never included in ExceptionOS. Users should not enter passwords, government identifiers, financial account numbers, medical records, or other secrets.

ExceptionOS does not sell data, run advertising, or include analytics or third-party trackers. A user can delete a goal and its history from the application.
